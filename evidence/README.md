# Evidence pack — WBS 3.10 demonstrator

## Rules

1. **No illustrative results.** Every value must come from the named project
   system, at the named commit or digest. Local command output is labelled as
   local and cannot substitute for HDE evidence.
2. **One chain of identity.** PR merge commit → Tekton revision → image digest →
   GitOps commit → Argo CD sync revision → running pod. Break the chain and the
   evidence is invalid.
3. **No secrets.** Redact tokens, passwords, private keys and registry
   credentials. Vault evidence shows key names and injection status, never values.
4. **Retain raw output.** Store logs/JSON under `evidence/run-<date>/` and link
   them from `wbs-3.10-record.md`.
5. **Reviewer independence.** The approver must not be the author; record the
   GitHub handle and timestamp.

## Local evidence

`evidence/local/local-verification.md` is generated by `scripts/verify.ps1` or
`scripts/verify.sh`. It records the exact commands, versions, test counts,
rendered manifests and any checks that could not run (for example, no Docker
daemon). It proves the repository state only.

## Completion statement

Task 3.10 is complete only when `wbs-3.10-record.md` has no outstanding rows,
the attestation is signed, and the owners have recorded the date and decision.
